# Getting help

Doseph is a prototype with one maintainer. There is no paid support and
no guaranteed answer time, but every report is read.

| You want to … | Go to |
|---|---|
| try it | the latest prototype under [Releases](https://github.com/Wokesay/doseph-software/releases), or build it ([`README.md`](README.md)) |
| report something that does not work | an issue with the [bug report form](https://github.com/Wokesay/doseph-software/issues/new?template=bug.yml) |
| give feedback on a prototype, or share an idea | an issue with the [feedback form](https://github.com/Wokesay/doseph-software/issues/new?template=feedback.yml) |
| report a vulnerability | never in public: [`SECURITY.md`](SECURITY.md) |
| contribute | [`CONTRIBUTING.md`](CONTRIBUTING.md) |

**Before you report:** search the open and closed issues, and say which
version you use (shown at the bottom of the menu) and how you run it.

**Real hardware:** the prototypes run in the simulator and are not meant
to dose into a real tank, so we cannot help with wiring a real setup yet.

Issues are public: please leave out passwords, access tokens, Wi-Fi
details and where you live.
